## Cara Menggunakan

1. **Masukkan File Anda**: 
   Letakkan semua file portfolio Anda ke dalam folder yang sesuai dengan nama file yang sudah ditentukan di atas.

2. **Format File**:
   - Konsultan: Word (.docx), Excel (.xlsx), PowerPoint (.pptx)
   - Penelitian: Word (.docx)
   - Scriptwriter: Word (.docx)
   - Sertifikasi: PDF (.pdf)

3. **Nama File**:
   Pastikan nama file sesuai dengan yang tertera di website (lihat file `index.html`). Jika ingin mengubah nama file, edit juga di `index.html` pada bagian `href="assets/folder/nama-file.ext"`.

4. **Ukuran File**:
   Disarankan ukuran file tidak terlalu besar (maksimal 10MB per file) agar loading website tetap cepat.

## Catatan

- File-file ini akan dapat diunduh oleh pengunjung website
- Pastikan file tidak mengandung informasi sensitif
- Backup file original Anda di tempat lain untuk keamanan
- Anda bisa menambah atau mengurangi jumlah file dengan mengedit `index.html`
